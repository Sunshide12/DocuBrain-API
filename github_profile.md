## Sobre Mí / About Me

Desarrollador Full Stack con experiencia en producción construyendo aplicaciones escalables y potenciadas con Inteligencia Artificial. Especializado en stacks modernos (React/Next.js, Laravel, Astro), arquitecturas serverless, bases de datos vectoriales y desarrollo de sistemas RAG (Retrieval-Augmented Generation). Priorizo el código limpio y las soluciones con impacto empresarial real.

* **Lenguajes:** TypeScript, PHP, Python
* **Frontend:** React, Next.js, Astro, Tailwind CSS
* **Backend:** Laravel, Node.js, Deno
* **Bases de Datos & Caché:** PostgreSQL, pgvector, MySQL, Redis, Supabase
* **IA & Modelos:** Sistemas RAG, Gemini, Claude, GPT
* **Infra & DevOps:** Cloudflare (Workers/Pages/R2), Vercel, Nginx, Linux
